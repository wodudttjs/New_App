버전: v1.0

작성일: 2026-01-20 (Asia/Seoul)

대상 플랫폼: iOS / Android (우선), Web(관리자/콘텐츠 CMS)

1. 배경 / 문제 정의
1.1 배경

FFWPU 관련 정보는 “말씀/설교”, “공식 소식”, “이념/원리 소개”, “커뮤니티(교회/지역 연결)”, “미디어 자료”, “기부/후원” 등 다양한 형태로 존재한다. 실제로 FFWPU USA의 공식 사이트는 “GOD’S DREAM, ONE FAMILY” 메시지와 함께 블로그/월드뷰/연결(커뮤니티 찾기)/기부 같은 허브 구조를 갖고 있으며 , 국제 HQ 성격의 Mission Support 사이트는 설교/영상/연설 모음(예: Mother’s Speeches) 같은 콘텐츠 축을 제공한다.

1.2 사용자 문제

(신도) 말씀/설교를 꾸준히 소비하고 싶은데, 모바일에서 찾기·이어보기·저장·알림이 불편함

(관심자) 교단 소개/원리/블로그 글을 중립적이고 정돈된 UX로 보고 싶음

(연구자) 연설/자료/출판물을 체계적으로 탐색/검색하고 싶음

(일반) “가까운 공동체/교회”를 지도 기반으로 쉽게 연결하고 싶음(커뮤니티 맵 기능 존재)

(조직) 공지/행사/캠페인을 안정적으로 전달(푸시/캘린더/뉴스레터)하고 싶음

2. 제품 목표 / 비목표
2.1 목표 (Goals)

핵심 콘텐츠 통합: 말씀/설교, 뉴스, 행사 캘린더, 원리/소개, 미디어(영상·사진·출판물), 교회/커뮤니티 찾기, 기부 안내를 “한 앱”에서 제공

차분한 영성 UX: 광고/알림/추천이 “기도·묵상·시청”을 방해하지 않도록 설계

개인화: 관심 주제/지역/언어 기반 추천 및 알림 구독

확장 가능 CMS: 콘텐츠 업로드/검수/번역/배포를 운영팀이 관리 가능(웹 관리자 콘솔)

2.2 비목표 (Non-goals)

“교단 공식 앱”으로 오인될 수 있는 브랜딩은 법/정책 검토 전 확정하지 않음(초기에는 비공식/정보 제공 고지 옵션 포함)

외부 결제(기부/헌금) “인앱 결제 완결”은 1차 출시에서 필수 아님(웹뷰/공식 결제 페이지 연동을 우선)

커뮤니티 실시간 채팅/DM(중재 비용 큼)은 V2 이후로 미룸

3. 성공 지표 (Metrics / OKR)
3.1 핵심 지표

MAU / WAU, D1/D7/D30 retention

말씀/설교: 재생 수, 평균 시청 시간, 이어보기율, 북마크율

뉴스/블로그: 기사 열람 수, 공유율

커뮤니티: “Find a community” 클릭 → 지도/리스트 조회 → 연락/길찾기 전환율

기부: Donate 진입 → 결제 페이지 이동 → 완료율

알림: opt-in 비율, 알림 클릭률, 알림 차단률

3.2 품질 지표

앱 시작 시간, 크래시율, ANR율

접근성: 큰 글씨/스크린리더 대응

콘텐츠 신뢰: 신고율/정정률/중복률

4. 사용자 / 페르소나

주 1~3회 이상 말씀/설교 소비, 행사/캠페인 참여, 기부/후원 관심

관심자(탐색 사용자)

푸시 알림(공지/행사/신규 설교) – 구독 설정 최소

광고/수익: 콘텐츠 본문 내 광고 금지, 피드 하단 1개 슬롯만

5.2 V1 (출시 2차)

신고/피드백/정정 요청 플로우

5.3 V2 (확장)

팟캐스트(사이트 메뉴에 Podcast 존재)

관리자 콘솔 고도화(추천 편성, A/B, 번역 워크플로우)

7.2 말씀/설교(핵심)
배경 근거

설교/증언 자료가 지속적으로 게시되는 구조 존재

Mother’s Speeches 같은 연설 아카이브 존재

기능

목록: 카테고리/태그/연도 필터, 정렬(최신/인기/길이)

상세:

영상 플레이어(기본) + 오디오 모드

본문(요약/전문 텍스트)

북마크, 공유, 이어보기

검색: 제목/설명/본문全文 인덱싱(가능하면)

AC

이어보기: 마지막 재생 위치 자동 저장

“묵상 모드”: 재생 중 화면 밝기/알림 최소화 옵션

네트워크 불안정 시 자동 화질/오디오 전환

7.3 소식(뉴스/블로그) + 공지
배경 근거

공식 사이트에 블로그/스토리 콘텐츠가 존재

기능

목록: 공지/기사/칼럼 분류, 태그, 검색

상세: 본문 + 이미지 갤러리 + 출처/작성일, 공유, 저장

“정정 요청”: 본문 오류 발견 시 운영팀에 리포트

AC

콘텐츠 상세에서 본문 내 “외부 광고 삽입” 금지

링크/인용은 출처 명시(저작권/신뢰성)

7.4 행사/캘린더
기능

월간 캘린더 + 리스트

행사 상세: 일시/장소/문의/참여 링크

관심 행사 저장 + 리마인더 푸시

(V1) 개인 캘린더 내보내기(ICS)

AC

행사 리마인더는 기본 OFF, 사용자가 구독 시 ON

시간대/지역(현지화) 정확히 표시

7.5 커뮤니티/교회 찾기
배경 근거

기능

지도/리스트 보기(현재 위치 기반)

지역 검색(국가/도시/키워드)

커뮤니티 상세: 주소/연락처/예배 시간/길찾기/문의

“방문 가이드”(초심자 안내)

AC

위치 권한 거부 시에도 지역 검색으로 사용 가능

길찾기: 사용 OS 기본 지도 앱으로 딥링크

7.6 미디어(영상/사진/출판물)
배경 근거

기능

탭: 영상 / 사진 / 출판물

출판물: PDF 뷰어(목차/검색은 V1)

영상: 목록 + 재생(YouTube/자체 CDN)

사진: 앨범/그리드/확대

AC

출판물 다운로드는 “저작권/배포권 확인된 것”만

대용량 미디어는 Wi-Fi 다운로드 옵션 제공

7.7 기부/후원
배경 근거

Donate 페이지 및 후원 유입 구조 존재

기능

V1: 목적 선택(캠페인/프로젝트) + 영수증 안내 + 히스토리(계정 연동)

AC

영상 플레이어 안정성(네트워크 적응)

9.2 접근성
